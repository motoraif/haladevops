## Setup Instructions

### For Formspree (Contact Form)

1. Go to [formspree.io](https://formspree.io)
2. Sign up for free account
3. Create a new form
4. Copy your form ID
5. Replace `YOUR_FORM_ID` in `index.html` with your actual form ID

### For Calendly (Booking)

1. Sign up at [calendly.com](https://calendly.com)
2. Set up your availability
3. Get your scheduling link
4. Replace the Calendly link in `index.html`

### GitHub Pages Setup

1. Go to repository Settings
2. Navigate to Pages
3. Select branch: `main`
4. Select folder: `/ (root)`
5. Save

### Custom Domain Setup

1. In repository Settings > Pages
2. Add custom domain: `haladevops.com`
3. In your domain registrar (e.g., Namecheap, GoDaddy):
   - Add A records pointing to GitHub Pages IPs:
     - 185.199.108.153
     - 185.199.109.153
     - 185.199.110.153
     - 185.199.111.153
   - Add CNAME record: `www` pointing to `motoraif.github.io`
